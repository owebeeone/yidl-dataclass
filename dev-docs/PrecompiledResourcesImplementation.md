# Compiler prerequisite execution sequence

This addendum executes the accepted amendment at
`356321965b9a527aeee66585235f6883c0312dd4`. It restates its prerequisite
checkpoints without changing the model API, artifact contract or performance
thresholds. The owner records each exact committed tuple and actual evidence.

| Checkpoint | Scope and completion gate |
| --- | --- |
| P1 — Python artifact support | Astichi artifact APIs/closed codecs and structural frontend, Python backend, independent state and failure diagnostics. Genuine missing-capability RED, same-target GREEN, canonical source-versus-artifact behavior and parser tripwires. Explicit Python selection is a staged test condition; native support remains outstanding. |
| P2 — Native restoration | Complete native IR/package codec and structural registration, binding/ref/pass operations, plus the accepted NativeLoweringAddendum retained-shell/hygiene finalizer and native pre-expansion; real capability advertisement and rebuilt extension. Native-only canonical/negative/parser/ownership checks; no selected-native Python fallback. |
| P3 — YIDL integration | Recursive opt-in resource emission/resolution, structural literal/import wrappers, nested edge/diagnostic evaluation, source-mode compatibility and candidate metadata. Existing golden outputs and whole-graph/parser gates pass. |
| P4 — Installed portability | All three supported producers/consumers, with Python/native combinations: nine minor pairs and four backend pairs, 36 combinations where applicable. Complete owning suites, installed wheels/sdists, resource/digest/regeneration and capability-mismatch checks. |
| Resume A | The actual Dataclass class/metadata/slot implementation begins with its own behavioral RED and through-YIDL GREEN. No prerequisite success is relabeled as product success. |

The sole drafter writes product/compiler code, tests, owning active docs and
sanitized test artifacts; it stops at each checkpoint. The owner verifies,
maintains the aggregate evidence index/experiment ledger and performs scoped GWZ
commits. No tags, publication, membership changes or unrelated files are included.
New compiler behavior updates its owning active summary and public documentation.

Focused Astichi commands run from its root with the current local sources, e.g.
`python -m pytest tests/test_compiled_template_artifacts.py -q`. The existing
canonical harness owns successful roundtrips and behavior; focused tests own
decoder limits, malformed input, cancellation, ownership and forbidden-parser
paths. Missing package/import/native setup failures are not behavioral RED.
Preserve negative runs and same-target positives before refactoring.

Preflight structural input before potentially expanding a graph: non-singleton
shared references, cycles, oversized/deep data and custom AST objects must fail
without exponential cloning or executing custom copying hooks. Semantic validation
continues on owned state. This implements the amendment's closed graph and object
envelope; it does not widen the public artifact or compile_ast contract.

Each final prerequisite gate includes the amendment's three-minor/backend matrix
and native parser-entry counters. Packaging uses candidate versions and exact
wheel hashes; earlier baseline wheels remain historical evidence. Modified Rust
source checks inspect disabled branches and enforce explicit conditional scopes.
Broader existing-code migration is not claimed.

The aggregate final product still requires Dataclass Plan stages A–H, Code/State
reviews, ordinary-performance targets, public-documentation usage, declarative
desk evidence and complete time/token/cost reporting. Any architectural failure
requires redesign before proceeding.

P2 architecture is additionally controlled by `NativeLoweringAddendum.md`,
accepted at `1f1bc534b460753e8cd91230e5349ea802c90b5c` after dual GO. See its
ReviewResult for the paused prototype and honest corpus-failure classification.
