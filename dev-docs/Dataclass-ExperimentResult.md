## Product and verification

Dataclass supplies one generated class with ordinary public slots, field-specific
policy/lazy properties, real stdlib Field/class metadata and supported helpers.
Named factories resolve processed constructor values, class providers and hidden
construction inputs; delayed consumers retain only the needed private inputs.
Const/frozen fields and explicit excluded mutable caches coexist. Equality,
ordering, hashing, repr, inheritance, copy/deepcopy/pickle and replacement follow
the documented compatible subset and explicit extensions. Post-init is deliberately
excluded. Authored modular YIDL produces the behavior through original Astichi 1.1.3
and YIDL 0.1.0; no std dynamic method generator or consumer AST repair substitutes
for it. Shared comparison YIDL is actually consumed by Undoable with field-local
logical comparison and separate legacy-compatible write detection.

## Experiment outcome, interventions and process departures

The original GO is 2026-10-12T03:36:48Z; the completion checkpoint is 2026-10-12T18:39:51Z,
wall elapsed 15h 3m 3s. Active coding/CPU/billing duration is not exposed as a
reliable metric and is unavailable, not zero. Actor durations overlap and must
not be summed as main elapsed time.

This was **not an uninterrupted successful one-shot**. The owner incorrectly
promoted parser-free/persisted-template preferences into compiler prerequisites,
made a P1 SDK commit and partial P2 work, and required a user scope correction.
That detour remains preserved/excluded, with its time/token/cost included. The
original supported route passed feasibility probes and delivered the consumer;
those SDK changes were unnecessary for this outcome. Subsequent work stayed in
the two authorized consumers, testing/docs/evidence/benchmarks. Broader findings
are separately classified as limitations/opportunities rather than permission.

Design used independent review and a genuine redesign of the small native write
comparison boundary before implementation. Some stages have genuine behavioral
RED→same-target GREEN; some broader goldens/verification were authored afterward.
These departures and failed/setup/oracle attempts are preserved; no strict
all-features-test-first TDD claim is made. Accessors use builtin property holding
specialized functions rather than literal composed @property spelling because of
an observed original backend identifier-scope pattern. Descriptor/body/bytecode
behavior is verified and the difference is documented.

The original cold benchmark chose accumulated 20 ms generator batches, creating
40–80 stdlib interpreters per batch. Its interrupted 11m38s attempt/source/rows
remain separate. The owner explicitly amended cold alone to individual fresh
first-decoration observations; ordinary calibration and all targets/counts stay
fixed. This is another recorded implementation-method correction, not a hidden
sampling relaxation or product speed fix.
