# Python 3.15 patch release

The operator requested Python 3.15 in the matrices and patch releases for all four
members: YIDL, Lifecycle, Dataclass and Undoable. Editable scope is their bounded
compatibility fixes, generated artifacts, tests, documentation, packaging and
release automation. Astichi, Cache and other packages remain reference-only.
Gearu owns release preparation, verification, versioning and immutable tags;
trusted GitHub workflows own registry publication.

## Published baseline

Dataclass **0.1.0** was successfully published through Gearu and the operator's
trusted publisher on 27 October 2026. Release commit:
`29df4366d835d8d24c6597db64ff72230b8c5338`.

- GitHub release: https://github.com/owebeeone/yidl-dataclass/releases/tag/v0.1.0
- Successful Ubuntu publication run: https://github.com/owebeeone/yidl-dataclass/actions/runs/40492415367
- PyPI: https://pypi.org/project/yidl-dataclass/0.1.0/

That release covers 3.12–3.14. Its six local source cells, installed wheel/sdist
examples/regeneration, exact-commit rechecks, six Ubuntu cells, package checks and
OIDC upload passed. It must not be relabelled as a Python 3.15 release.

## Concrete 3.15 failures and bounded fixes

Final CPython **3.15.2** first failed during import because dataclasses removed
its private `_MISSING_TYPE` class. The marker annotation now derives that type
from public `MISSING`, retaining identity-based sentinel behavior on all supported
minors. After that fix, the unresolved-annotation freeze test exposed removal of
`dataclasses._is_type`. The metadata adapter now uses the interpreter's replacement
non-evaluating `_get_type_from_annotation` helper on 3.15 and the previous helper
on older supported minors. No user methods are generated by std dataclasses.

The runtime guard and package cap now include 3.15, the unsupported-minor negative
test advances to 3.16, and lazy annotation preservation also runs on 3.15. All
versioned canonical source manifests now include actual generated 3.15 outputs,
produced by the supported refresher after the canonical stories execute.
The focused marker/freeze/inheritance suite passed: **45 passed, 1 skipped**.
The complete source suite on final 3.15.2 passed on both explicit backends:
**287 passed, 1 skipped** each. Release-worktree and publication checks will
verify the final dependency tuple separately.

## Target and dependency order

Target Dataclass patch: **0.1.1**, after YIDL **0.1.2** is published and verified.
Its exact compiler pin will be updated to that published release and regeneration
reviewed. Lifecycle **0.1.1** separately adopts that compiler after its own
regeneration checks. Undoable **0.1.1** uses the published Dataclass 0.1.1 shared
comparison authority at regeneration time, with its existing SHA256 gate.

The freeze operation remains optimistic and non-transactional; this compatibility
patch does not introduce rollback or thaw. Historical review/performance evidence
keeps its original scope. This pass adds no unmeasured performance claim.

## Platform boundary

See `Python315DependencyFindings.md` for the confirmed missing Windows cp315
wheel in Astichi 1.1.3. This pass qualifies macOS locally and Ubuntu in publication
CI; it does not certify Windows Python 3.15 or an untested SDK source build.
